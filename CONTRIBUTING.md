# Contributing

## Development Setup

Install:

- Rust
- Node.js
- Tauri
- Git

Clone repository.

Install frontend:

npm install

Run:

cargo tauri dev

## Pull Requests

Requirements:

- Build passes
- No hardcoded paths
- No fake runtime logic
- No mock inference

## Coding Standards

Rust:
- Clippy clean
- cargo check clean

Frontend:
- TypeScript strict mode

Documentation:
- Update changelog
- Update lessons learned
