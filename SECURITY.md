# Security Policy

## Reporting Vulnerabilities

Do not publish security vulnerabilities publicly.

Report issues privately to project maintainers.

Include:

- Description
- Reproduction steps
- Impact
- Environment

## Scope

Current scope includes:

- Runtime execution
- Model loading
- IPC communication
- Database access
- File discovery system

## Security Principles

- Fail Closed
- No Hidden Fallbacks
- Explicit Runtime Validation
- Local First
